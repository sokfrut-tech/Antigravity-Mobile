# App icon standard

Every Android app in this project family must ship with a deliberate, polished, project-specific launcher identity.

## Required deliverables
- A recognizable symbol that remains legible at small launcher sizes; do not rely on text in the primary mark.
- Android adaptive icon resources for foreground and background.
- Legacy launcher fallback for devices that do not use adaptive icons.
- Both standard and round launcher manifest attributes.
- Consistent visual language with the product brand, without copying another product's trademark artwork.
- Verify icon rendering in the Android emulator and inspect launcher screenshots before release.

## Design direction
Use a distinctive symbol, restrained palette, clean geometry, balanced negative space, and production-quality contrast. Avoid generic default Android icons, emoji, clip-art, and unreviewed placeholder assets.

For each new project, create a unique icon appropriate to that product rather than reusing this app's artwork.
